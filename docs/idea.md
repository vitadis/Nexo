# Nexo

## Descripción

**Nexo** es una plataforma diseñada para facilitar y modernizar la comunicación entre empresas y candidatos durante todo el proceso de selección. Su objetivo es ofrecer una experiencia transparente, rápida y organizada tanto para el empleador como para el empleado, centralizando la gestión de ofertas, candidaturas y comunicación en una única aplicación.

---

# Objetivos

* Simplificar los procesos de contratación.
* Mejorar la comunicación entre empresas y candidatos.
* Reducir los tiempos de selección.
* Ofrecer transparencia sobre el estado de cada candidatura.
* Ayudar a los candidatos a potenciar su perfil profesional.
* Permitir que las empresas encuentren talento de forma más eficiente.

---

# Funcionalidades para Empresas

## Gestión del perfil empresarial

* Personalizar el perfil de la empresa.
* Añadir logotipo, descripción e imágenes.
* Configurar cultura empresarial, beneficios y valores.
* Mostrar ubicación y centros de trabajo.
* Ver estadísticas de visitas al perfil.

## Gestión de ofertas de empleo

* Crear nuevas ofertas.
* Editar ofertas existentes.
* Pausar o cerrar vacantes.
* Duplicar ofertas para futuras contrataciones.
* Programar la publicación de ofertas.

## Gestión de candidatos

* Ver todos los candidatos inscritos.
* Acceder al perfil completo de cada candidato.
* Descargar el CV.
* Consultar estudios, experiencia y certificaciones.
* Ver idiomas, competencias y tecnologías dominadas.
* Añadir notas privadas sobre cada candidato (se informara mediante un gmail).
* Marcar candidatos como favoritos.

## Filtros avanzados

Buscar candidatos mediante filtros como:

* Estudios.
* Experiencia laboral.
* Aptitudes.
* Idiomas.
* Tecnologías.
* Ubicación.
* Disponibilidad.
* Tipo de contrato.
* Jornada laboral.
* Salario esperado.

## Gestión del proceso de selección

Cada candidatura tendrá un estado visible.

Ejemplo:

* Solicitud recibida.
* Perfil revisado.
* Primera entrevista.
* Prueba técnica.
* Entrevista final.
* Oferta enviada.
* Contratado.
* Candidatura rechazada.

## Comunicación

* Chat directo con los candidatos.
* Solicitud de documentación.
* Envío de mensajes masivos.
* Invitación a entrevistas.
* Notificaciones automáticas.

## Estadísticas

* Número de candidaturas.
* Tiempo medio de contratación.
* Conversión por oferta.
* Perfil de candidatos más buscados.
* Rendimiento de las ofertas publicadas.

# Funcionalidades para Empleados

## Perfil profesional

Cada usuario dispondrá de un perfil similar a un currículum digital.

Incluyendo:

* Foto.
* Presentación personal.
* Estudios.
* Formación complementaria.
* Experiencia laboral.
* Idiomas.
* Certificados.
* Aptitudes.
* Tecnologías.
* Portafolio.
* Proyectos.
* Enlaces a LinkedIn, GitHub u otras plataformas.

## Gestión de candidaturas

El usuario podrá:

* Ver todas las ofertas solicitadas.
* Consultar el estado actualizado de cada candidatura.
* Recibir notificaciones de cambios.
* Retirar una candidatura.
* Guardar ofertas como favoritas.

## Búsqueda de empleo

Filtros disponibles:

* Ciudad.
* Trabajo remoto.
* Jornada.
* Salario.
* Sector.
* Empresa.
* Experiencia requerida.
* Tipo de contrato.
* Tecnologías.
* Fecha de publicación.

## Asistente Inteligente

Un asistente integrado ayudará al usuario a mejorar sus posibilidades de contratación.

Funciones:

* Analizar el perfil.
* Detectar información incompleta.
* Recomendar habilidades demandadas.
* Mejorar la descripción profesional.
* Sugerir cursos.
* Optimizar el currículum.
* Simular entrevistas.
* Generar respuestas para preguntas frecuentes.

## Alertas personalizadas

El usuario podrá configurar alertas para recibir notificaciones cuando aparezcan ofertas que coincidan con sus preferencias.

# Comunicación entre Empresa y Empleado

Nexo permitirá mantener una comunicación fluida durante todo el proceso.

Funciones:

* Chat integrado.
* Confirmación de entrevistas.
* Reprogramación de entrevistas.
* Videollamadas (futuro).
* Compartir documentos.
* Notificaciones en tiempo real.
* Historial completo de conversaciones.

# Sistema de Notificaciones

Notificaciones para:

* Nueva candidatura.
* Cambio de estado.
* Mensajes recibidos.
* Invitación a entrevista.
* Rechazo.
* Oferta laboral.
* Actualización del perfil.
* Nuevas ofertas recomendadas.

---
# Sistema de autenticación y verificación

* Autenticación en dos pasos (2FA).
* Verificación del correo electrónico.
* Verificación de títulos y certificados.
* Verificación de identidad de empleados.
* Verificación de empresas.
* Insignia de perfil verificado.
* Detección de cuentas fraudulentas o duplicadas.

El administrador podrá:

* Moderar contenido.
* Eliminar cuentas fraudulentas.
* Revisar reportes.

# Objetivo final

Nexo busca convertirse en una plataforma donde empresas y candidatos puedan encontrarse de forma rápida, transparente y eficiente. Más allá de publicar ofertas de empleo, pretende acompañar a ambas partes durante todo el proceso de selección, ofreciendo herramientas que faciliten la contratación, mejoren la comunicación y ayuden a crear relaciones laborales de mayor calidad.
